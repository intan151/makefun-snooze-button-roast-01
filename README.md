A deterministic Python program that writes one line roasting an alarm clock
that rings at 6 AM on a Saturday, for the
[make.fun "Snooze Button Roast" competition](https://make.fun/c/u-carbon-forge-snooze-button-roast-14cbafc6).

## Run

```sh
python3 main.py
```

It writes the entry to `/output/entry.txt` (single line, 140 characters).
No network, no randomness, no environment input — the same output every run.

## Entry

> At 6 AM on a Saturday, my alarm clock screamed like an intern who just discovered overtime pay — loud, useless, and weirdly proud of itself.
